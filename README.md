# 作図ノート v8 — 図形発見・証明支援アプリ（教材完全版）

> 小・中・高の図形単元を対象とした、**「動かして発見 → 作図して確かめる → 根拠を選んで証明する」**を1つの画面で支援する教材ツールです。
> 
> ブラウザ1つで動作し、サーバ不要・インストール不要です。

---

## 🎯 このアプリでできること

| 対象 | できること |
|---|---|
| **生徒** | 図を自由に動かす、作図する、観察メモを書く、根拠カードを選ぶ、証明の骨組みを組み立てる、証明文章を完成させる |
| **先生** | 課題パックを作る、授業シナリオを確認する、ルーブリック評価を行う、複数生徒の提出を一覧で見る、作図履歴を再生する、印刷ワークシーを作る |

**1ファイルHTML**で動作します。インターネット接続は不要（CDNフォント以外）。

---

## 🚀 クイックスタート

### 生徒の方へ

1. `作図ノート_v8_教材拡張版.html` をブラウザで開く
2. 左上で **学年** と **単元** を選ぶ
3. **授業課題** または **作図手順** を選ぶ
4. キャンバス上で **点を動かしたり、線分や円を作ったり** する
5. **観察メモ** に気づきを書く
6. **根拠カード** を選んで **証明の骨組み** を組み立てる
7. **提出データ** をJSONで保存して先生に渡す

### 先生の方へ

1. `作図ノート_v8_教材拡張版.html` をブラウザで開く
2. **先生用・課題作成** でオリジナル課題を作る
3. **課題パック書出** でJSONを保存し、生徒に配布する
4. 生徒から集めた **提出JSON** を **提出JSON複数読込** で一覧確認する
5. **ルーブリック評価** で自動評価案を確認し、点数を調整する
6. **印刷ワークシート** で紙のプリントを作る

## 📐 対応単元と課題数（12単元 × 3課題 = 36課題）

| 単元 | 課題1 | 課題2 | 課題3 |
|---|---|---|---|
| **円周角** | 同じ弧を見る円周角 | 中心角と円周角の関係 | 接弦定理の発見 |
| **平行線と角** | 同位角・錯角の予想 | 平行線を使った角の計算 | 角から平行を判断する |
| **合同条件** | 2辺とその間の角 | 直角三角形の合同 | 合同から対応部分を求める |
| **相似条件** | 2組の角が等しい | 3辺の比が等しい | 相似比を使った長さの計算 |
| **三平方の定理** | 直角三角形の3辺の関係 | 三平方の定理の逆 | 空間図形への応用 |
| **面積** | 高さが同じ三角形の面積 | 平行四辺形の面積 | 等積変形の活用 |
| **対称** | 線対称の対応点 | 点対称の中心 | 対称な図形の作図 |
| **円と正多角形** | 半径が等しいことを確かめる | 円から正六角形を作る | 中心角と正多角形 |
| **三角比** | 角が同じ直角三角形の辺の比 | 単位円でsinとcosを見る | 三角比を使った高さの計算 |
| **ベクトル** | 平行四辺形でベクトルの和 | 平行なベクトル | ベクトルの成分表示 |
| **軌跡** | 一定距離にある点の軌跡 | 2点から等距離の点の軌跡 | 条件を変えた軌跡 |
| **図形と方程式** | 円と直線の交点の個数 | 接線と中心からの距離 | 2円の位置関係 |

## 👦 生徒向け詳細ガイド

### 1. 図を動かして観察する

- キャバス上の **点をドラッグ** して動かせます
- 点をクリックしてから別の点をクリックすると **線分** が作れます
- ツールバーで「円」「垂線」「平行線」などを選んで作図できます

### 2. 観察メモを書く

- **観察メモ** パネルに気づきを書きます
- 「等しい」「平行」「垂直」「同じ弧」などのキーワードが自動検出されます
- メモが具体的かどうかがスコア化されます

### 3. 根拠カードを選ぶ

- **根拠カード** から証明に使えそうな定理を選びます
- 選んだカードが **証明の骨組み** に反映されます
- カードを選び直すこともできます

### 4. 証明を完成させる

1. **証明の骨組み** で穴埋え形式で証明の流れを確認
2. **証明の文章化** で接続詞を選びながら文章を書く
3. **文章チェック** で主語・根拠・接続詞の有無を確認
4. **証明JSON** で保存

### 5. 作図手順モード

- **作図手順** を選ぶと、制限付きの作図に挑戦できます
- 使える道具が制限される場合があります
- 手順ごとに正誤判定が行われます

### 6. データの保存

- **提出データ** パネルでJSONまたはTXTで保存
- ファイル名に名前・クラス・日付が自動付加されます
- 先生にファイルを渡すだけで提出完了

## 👨‍🏫 先生向け詳細ガイド

### 1. 課題パックの作成と配布

1. **単元プリセット** で学年・単元を選ぶ
2. **先生用・課題作成** で問い・ヒント・証骨組みを入力
3. **課題パック書出** でJSONを保存
4. 生徒にJSONファイルを配布（メール、LMS、USBなど）
5. 生徒は **課題パック読込** で読み込む

### 2. 授業シナリオの確認

- **授業シナリオ** パネルで5段階の流れを確認
  1. 導入
  2. 自由探索
  3. 発見共有
  4. 証明
  5. 練習問題
- **シナリオJSON** で書き出し、授業参観や共有に活用

### 3. 提出データの一括確認

1. **先生ビュー・提出一覧** を開く
2. **提出JSON複数読込** で生徒のJSONファイルを複数選択
3. 一覧で以下を確認：
   - 単元・課題名
   - 観察メモ（冒頭70文字）
   - 選んだ根拠カード
   - 測定値
   - メモ分析スコア
   - 操作ログ件数

### 4. ルーブリック評価

1. **ルーブリック評価** パネルを開く
2. **自動評価案** を押すと、作図ログ・メモ・根拠から自動で点数案が出る
3. 5観点（手順・対象選択・意味説明・観察・証明）を0〜4点で調整
4. 合計20点満点で評価
5. **評価JSON** で書き出し

### 5. 作図履歴の再生

1. 生徒の提出JSONを読み込む（または生徒に画面を見せてもらう）
2. **作図履歴再生** パネルを開く
3. **再生** ボタンで自動再生（速度調整可能）
4. **一時停止** で途中停止、**前/次** で1ステップずつ確認
5. 各ステップに **コメント** を追加して記録

### 6. 印刷ワークシートの作成

1. **印刷ワークシート** パネルを開く
2. **穴埋め版** または **白紙版** を選ぶ
3. **プレビュー更新** でレイアウトを確認
4. **印刷** ボタンでブラウザ印刷（PDF保存も可）

### 7. 外部連携

- **TikZ出力**：LaTeX文書にそのまま貼り付け可能なTikZコードを生成
- **LMS提出形式**：Google Classroom等に対応したJSON形式で出力
- **GeoGebra参照**：GeoGebraの図URLを貼り付けて別タブで参照

## ⚠️ 注意事項・制限

### 協働モードについて
- **同一ブラウザ・同一PC内**のlocalStorage共有です
- 別PC・別ブラウザ間のリアルタイム連携にはサーバが必要です
- 同一PCの別タブ間では2秒間隔で自動同期されます

### 学習履歴について
- **ブラウザのlocalStorage**に保存されます
- ブラウザを変える・キャッシュを消すと消えます
- 長期保存には **履歴JSON書出** を定期的に行ってください

### TikZ出力について
- 点・線分・円・垂線・平行線・角・接線・注釈に対応
- 複雑な図形は手動調整が必要な場合があります
- 使用には `\usetikzlibrary{angles,quotes,arrows.meta}` が必要です

### 音声読み上げについて
- **Web Speech API**対応ブラウザ（Chrome, Safari, Edge等）で動作
- Firefoxでは非対応の場合があります

### 推奨環境
- **Chrome** 最新版（最も動作確認済み）
- **Edge** 最新版
- **Safari** 最新版
- 画面幅：1280px以上推奨（タブレットでも可）
